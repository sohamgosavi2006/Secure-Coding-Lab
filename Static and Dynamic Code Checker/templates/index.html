JavaCodeCheck — Educational Code Analysis Lab

A practical, interactive laboratory demonstrating how static analysis, bytecode inspection, runtime unit testing, and code coverage work together to detect and remediate security vulnerabilities in Java software.

Static Code Analysis (PMD & SpotBugs)

Evaluates source code (AST) and compiled bytecode (.class files) without executing the program. Finds potential bugs, structural anti-patterns, missing boundary checks, and resource leaks early in the SDLC.

Dynamic Runtime Testing (JUnit 5 & JaCoCo)

Executes compiled code inside the Java Virtual Machine using test cases. Verifies expected versus actual behavior, measures line and branch coverage, and reveals how unexpected inputs trigger runtime exceptions.

About the Four Analysis Tools

Comprehensive reference explaining tool roles, mechanisms, and secure coding practices.

Static Analysis #1

PMD 7.0.0

PMD analyzes Java source code directly without compiling it. It converts code into an Abstract Syntax Tree (AST) and evaluates XPath and Java-based rules against that tree.

Static Analysis #2

SpotBugs 4.8.6

SpotBugs operates on compiled Java bytecode (.class files) using ObjectWeb ASM. It builds control flow graphs and inspects class structures to detect bug patterns.

Dynamic Testing

JUnit 5 (Jupiter)

JUnit 5 is the modern test execution framework for Java. It executes dynamic test methods inside the JVM, verifying assertions and catching unexpected exceptions.

Dynamic Coverage

JaCoCo 0.8.12

JaCoCo uses a Java Virtual Machine Tool Interface (JVMTI) Java Agent to instrument bytecode on-the-fly, recording line-by-line and branch execution counts.
